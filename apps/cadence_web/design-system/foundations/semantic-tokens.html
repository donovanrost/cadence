✓ Implemented (step 1) — the role layer is seeded in tokens.css; ◎ component migration off --glow-* continues (Phase 5).

The role layer from Token architecture, made concrete. Most of Cadence is already here — --surface-*, --status-*, --text-* are already semantic roles. What's still fused to the skin is the interactive action color (it borrows the skin name --glow-cyan) and the cyan border family. This card defines those roles.

Non-breaking by design: each role is an alias onto a token that already exists, so nothing changes until components migrate to the role names one at a time. Old names keep working throughout.

The fusion fix

Before — skin name doing a role's job

/* a SKIN name carries the meaning */
--glow-cyan: var(--brand-primary);

/* component borrows the skin name */
.text-primary { color: var(--glow-cyan); }

After — role aliases the skin

/* OUTFIT role points at the skin */
--color-action: var(--glow-cyan);

/* component consumes the ROLE */
.text-primary { color: var(--color-action); }
/* swap the skin → the role holds */

The tokens.css block (step 1, shipped)

/* ── OUTFIT · semantic role tokens — added to the existing :root.
   Named by MEANING, aliased onto the skin. New component code consumes
   these; re-theming swaps what they point at. Non-breaking. ── */
--color-action:            var(--glow-cyan);
--color-action-strong:   var(--cyan-600);
--color-action-secondary:  var(--glow-purple);
--color-action-accent:     var(--glow-pink);
--on-action:               oklch(15% 0.02 210);

--border-subtle:  oklch(from var(--color-action) l c h / 0.15);
--border-default: oklch(from var(--color-action) l c h / 0.25);
--border-strong:  oklch(from var(--color-action) l c h / 0.40);
--border-focus:   oklch(from var(--color-action) l c h / 0.60);

Fits the frozen-CSS rule: this only adds custom-property tokens to the existing :root (rule 1 permits that) — no new selectors. Step 2 then parameterizes the flourishes (--fx-glow, --label-case, --pulse-*) so a legibility skin and reduced-motion become a few token reassignments.
