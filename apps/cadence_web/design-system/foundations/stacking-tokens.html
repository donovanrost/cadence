Stacking tokens (spec)

✓ Implemented — the z-scale is live in tokens.css and every template literal is migrated. ◎ The scrim tokens (--scrim-bg, --scrim-blur) wait for the first modal that needs them.

Replaces the ad-hoc z-soup (z-[5]×12, z-[100], z-50) with a named, sparse scale. Verified: Cadence overlays are div-based (no native <dialog>), so z-index fully governs — the enum is sufficient, no top-layer special-casing.

The scale

/* :root — named z-tiers, spaced 100 apart so you can insert without renumbering */
--z-base:     0;     /* normal flow */
--z-sticky:   100;   /* pinned headers / toolbars */
--z-chrome:   200;   /* persistent frame: sidebar, ops status bar */
--z-popover:  300;   /* dropdowns, menus, action-menu, widget popovers */
--z-scrim:    400;   /* modal backdrop */
--z-modal:    410;   /* dialog content — just above its scrim */
--z-toast:    500;   /* flash / notifications */
--z-tooltip:  600;   /* always on top */

Order is deliberate: toast & tooltip sit above modal — transient info must stay visible over a dialog. scrim + modal are a paired couplet (backdrop just below content).

What it fixes

✓ Popovers were below chrome. Today widget popovers (z-[5]) sit under the sidebar / status bar (z-50/100) — a popover can be clipped by the chrome. The enum makes popover (300) > chrome (200), so overlays always clear the frame.

✓ Flash and menus shared z-[100] with no defined order. Now toast (500) > popover (300) — a notification never hides behind an open menu.

The scrim — a real layer

--scrim-bg:   oklch(0% 0 0 / 0.55);   /* dim the world behind a modal */
--scrim-blur: blur(2px);            /* optional: frost the content too */

/* a full-viewport overlay at --z-scrim: dims + blurs + blocks pointer events;
   modal content sits at --z-modal, just above. This is the literal
   enforcement of "you may not touch what's behind." */

Today daisyUI's modal-backdrop only dims. Formalizing the scrim (dim + blur, reusable for any modal / sheet) makes the "permission" half of layering first-class.

Rules

  • ✓ Every out-of-flow overlay reads a --z-* token — never a literal z-[n].
  • ✓ Toast & tooltip stay above modal; chrome stays below popover. The order encodes the rules.
  • ✓ Need a new layer? Add a named token in a 100-gap — don't squeeze a magic number between tiers.
  • ✗ Don't promote persistent chrome above transient popovers — chrome < popover is intentional.
  • ✗ Don't use the enum for sibling ordering inside one component — that stays local.

Fits the frozen-CSS rule: adds :root tokens and swaps existing z-[n] for var(--z-*) (value-tuning) — no new selectors.
