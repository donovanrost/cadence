Foundations

Token architecture

Cadence's look is split into three layers so the sci-fi aesthetic becomes a skin you can take off — not a fact welded into every selector. This is what makes re-theming, a high-legibility "ops mode", and prefers-reduced-motion possible without touching component code.

△  The one rule: dependencies only point down. Body → Outfit → Skin. Components never reach past Outfit.

The three layers

BODY · structure

Anatomy, layout, spacing rhythm, hierarchy, interaction & a11y contracts. Not tokens — it lives in the component & pattern cards. Survives any reskin.

card: title · body · accentform: narrow · single-columntable: name-cell linksfocus & disabled contracts

OUTFIT · semantic roles

Roles named by meaning, pointing at the skin. The swappable layer — a theme repoints these; component code never changes.

--color-action--surface-raised--status-critical--text-muted--border-subtle--label-case

SKIN · primitives + effects

Raw sensory values and decorative flourishes. No inherent meaning. This is what you swap to re-theme or dial down for legibility.

oklch(80% .12 210)--fx-glow step 2--fx-corner-size: 12px step 2--pulse-critical: 0.5s step 2uppercase

Which layer? — the litmus test

  • BODYWould it still be true if Cadence were reskinned to look like a plain gray enterprise app? Yes → body.
  • OUTFITWould a daylight / legibility / white-label theme repoint it while the role persists? Yes → semantic token.
  • SKINIs it a raw value or a flourish with no meaning of its own (a specific oklch, the glow, the strobe, the uppercase itself)? → skin.

Usage

  • ✓ Components consume Outfit roles (var(--color-action), --surface-raised) — never Skin primitives or raw oklch.
  • ✓ A new theme is a new Skin under the same Outfit; the Body never moves.
  • ✓ Keep structure in the component / pattern cards, not in tokens.
  • ✗ Don't reference --glow-* / --brand-* / raw oklch in component code — that re-fuses skin to structure.
  • ✗ Don't mint a role for a one-off; the Outfit layer is a small shared vocabulary, not a per-use dumping ground.
