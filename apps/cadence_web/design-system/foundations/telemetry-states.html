Foundations

Telemetry value states

◎ Grounded in the real model (limits/evaluator.ex, telemetry/sample.ex). The model is current; the unified rendering is proposed.

A telemetry value answers three independent questions at once, and Cadence already models all three. Conflating them is the classic ops-display failure. They compose: a value can be in-limit but stale, or in red alarm but untrustworthy.

LIMIT

Is it within mission limits? red · yellow · green · blue

QUALITY

Can the value be trusted? good · suspect · bad

FRESHNESS

Is it current? fresh · stale · gap

Axis 1 — Limit state current

Six granular states collapse to the four-state normalized_state that is the UI contract. Map straight onto the status palette (and badge-error/warning/success/info). Always pair the color with the granular label — R-HI, Y-LO — so it survives colorblindness.

:red_low  :red_high :yellow_low  :yellow_high :green :blue
→
:red · severity 2 :yellow · severity 1 :green · severity 0 :blue · severity 0

Axis 2 — Quality current model, proposed rendering

quality_state is orthogonal to limit — it's about trust, not range. It does not recolor the value (limit owns color); it annotates.

37.4 V — good · no mark 37.4 V ⚠ — suspect 37.4 ⊘ BAD — struck + flagged

Axis 3 — Freshness proposed

Inferred in the UI from receipt_time (no core flag). Fresh values may carry the "live" glow (glow means live); stale values dim and timestamp; a gap is rendered as explicit absence — never a held-over number.

37.4 V — fresh / live 37.4 V stale · 14:02:11Z — — NO DATA

Composition — the hierarchy

Limit colors. Freshness dims. Quality flags. One channel per axis, so all three can show at once without fighting. Examples:

42.1 V R-HI red limit · fresh → live alarm (color + label + glow)
37.4 V stale · 14:02Z in-limit but stale → nominal hue, dimmed, timestamped
29.8 V Y-LO ⚠ caution limit + suspect quality → yellow + label + caution glyph

Usage

  • ✓ Drive value color from limit, intensity from freshness, an annotation from quality — one visual channel each.
  • ✓ Always pair limit color with its granular label (R-HI/Y-LO) or a shape — never color alone (colorblind safety).
  • ✓ Reserve the "live" glow for genuinely fresh values; a stale value must visibly lose it.
  • ✗ Never render a stale value as if it were live. Dim it and show its age — an old number presented as current is the cardinal ops-display sin.
  • ✗ Never substitute 0 (or a held last value) for missing data — a gap is explicit absence (— / NO DATA).
