Effect tokens & skins

✓ Implemented (step 2) — the knobs are live in tokens.css, wired through the CSS, and [data-skin="legible"] ships in app.css. ◎ ~54 Tailwind uppercase utilities in templates still bypass --label-case.

Step 1 named the roles; step 2 makes the flourishes dial-able. Today the glow, the uppercase labels, and the pulsing dots are hardcoded literals in the HUD utilities, so you can't turn them down. Here each becomes a Skin token the utilities read — which is what finally makes a high-legibility mode and prefers-reduced-motion possible without touching a single component.

The knobs

TokenDefault (HUD skin)DialsLegibility / reduced
--fx-glow-strength1All neon glow — multiplies every glow's opacity.0
--label-caseuppercaseCasing of hud-label, card titles, badges, table heads.none
--label-tracking0.12emLetter-spacing on those same labels.0.02em
--pulse-nominalhud-pulse 2s …Nominal status-dot breathe.none
--pulse-warninghud-pulse-warning 1s …Warning status-dot blink.none
--pulse-criticalhud-pulse-critical 0.5s …Critical status-dot strobe.none *
--fx-scanline-opacity0.03The scanline overlay intensity.0
--fx-corner-size12pxLength of the hud-corners brackets.12px (kept)

* A skin can retune rather than kill: legibility could swap the critical strobe for a gentle hud-pulse 1.6s opacity fade — attention without the photosensitive 0.5s scale-strobe. Removing motion never removes meaning here: the dot keeps its red color and shape, so status survives with the animation gone.

How a utility reads a knob

Before — hardcoded literal

.glow-cyan {
  box-shadow:
    0 0 10px oklch(from var(--glow-cyan) l c h / 0.5),
    0 0 20px oklch(from var(--glow-cyan) l c h / 0.3);
}
.hud-label {
  text-transform: uppercase;
  letter-spacing: 0.12em;
}
.hud-status-critical .hud-status-dot {
  animation: hud-pulse-critical 0.5s …;
}

After — reads the Skin knob

.glow-cyan {
  box-shadow:
    0 0 10px oklch(from var(--glow-cyan) l c h / calc(0.5 * var(--fx-glow-strength))),
    0 0 20px oklch(from var(--glow-cyan) l c h / calc(0.3 * var(--fx-glow-strength)));
}
.hud-label {
  text-transform: var(--label-case);
  letter-spacing: var(--label-tracking);
}
.hud-status-critical .hud-status-dot {
  animation: var(--pulse-critical);
}

This is value-tuning of existing declarations plus new tokens — no new selectors — so it stays inside the frozen-CSS rule. The only added selector is the [data-skin] root below, which is the same family as the existing [data-theme="light"] / [data-theme="dark"] roots.

Consumer 1 — reduced motion (automatic)

/* respects the OS setting; kills only decorative motion */
@media (prefers-reduced-motion: reduce) {
  :root {
    --pulse-nominal:  none;
    --pulse-warning:  none;
    --pulse-critical: none;
  }
}

Consumer 2 — the legibility skin (opt-in)

A second axis that composes with data-theme (so legible works in dark or light). Same Body, same Outfit roles — only the Skin knobs flip.

[data-skin="legible"] {
  --fx-glow-strength:    0;         /* no glow */
  --label-case:          none;      /* sentence-case labels */
  --label-tracking:      0.02em;
  --pulse-nominal:       none;
  --pulse-warning:       none;
  --pulse-critical:      none;
  --fx-scanline-opacity: 0;
  /* and lift the lowest-contrast tier while we're here */
  --border-subtle:       oklch(from var(--color-action) l c h / 0.30);
}

What this unlocks — and what it doesn't

  • ✓ Reduced-motion respected — the 0.5s critical strobe was a genuine photosensitivity / fatigue risk in a 24/7 ops room. Now it's gone for anyone who asks the OS for it.
  • ✓ Legibility mode — drops the uppercase-tracked-tiny labels (the single biggest readability tax) and the glow, in one attribute.
  • ✓ Re-skinnable — the same knobs are how a future theme or white-label restyles without re-architecting.
  • ✗ Does not fix the palette's raw contrast ratios — that's a Skin value audit (verify the oklch text/border pairs against AA), separate work.
  • ✗ Does not address color-only status in charts / limits — that belongs to the data-visualization foundations (still unbuilt).
