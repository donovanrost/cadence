Foundations

Content & terminology

Language is design surface — especially for a domain tool. Cadence speaks operator-to-operator: precise, terse, calm, technical. The words carry meaning the way the colors do, so they're a controlled vocabulary, not free prose.

Voice & tone

  • Precise & technicalUse the real domain terms; operators know them. Don't dumb down "decommutation" to "data parsing."
  • TerseOperators scan. Cut filler — "Create transport," not "Click here to create a new transport."
  • Calm & factualThe UI signals urgency (color, motion); the words stay measured. No "Oops!", no exclamation marks.
  • Peer, not hand-holdingTalk to a professional, not a worried novice. No "Don't worry," no reassurance theatre.
  • Active, present tense"Transport is active," not "The transport has been successfully activated."

Established ops abbreviations are kept, not spelled out — Comms, Ops, SCID, AOS/LOS, decom, TLM/CMD. Operators read them faster than the full words. Spell out only in onboarding / help.

Casing

Author labels in their natural case — "Deploy," "Battery voltage," "New transport." The UPPERCASE you see on labels is a presentational skin (--label-case), not content — the legibility mode turns it off. Never write all-caps into content or data, or it can't be undone.

Time & numbers

  • UTC, alwaysSpacecraft ops can't tolerate timezone ambiguity. Times are HH:MM:SSZ, timestamps YYYY-MM-DDTHH:MM:SSZ. Never local time. Relative ("2m ago") only as a secondary hint.
  • Units, alwaysShow the unit as a dim suffix (98.2 V); never a bare number. Fixed precision per telemetry point. Tabular figures so streaming values don't twitch.
  • Missing ≠ zeroNo data renders as an em dash —, never 0 or blank. Identifiers are monospace, truncated with the full value on hover.

Copy patterns

Empty stateState the absence + the next action. "No transports yet. Create one to describe a byte-moving capability."
ErrorWhat failed + why + the fix. Never "Something went wrong." → "Transport not created — port must be 1–65535."
ValidationLowercase, specific, on the field. "can't be blank," "must be between 1 and 65535."
Action labelVerb + noun, specific. "Create transport," "Save identity," "Abort pass." Never "Submit" / "OK". Name destructive actions: "Delete spacecraft."

Voice — before / after

✗ Not Cadence

"Oops! Something went wrong while creating your transport. Please try again later!"

"Awesome — your spacecraft is all set up! 🎉"

✓ Cadence

"Transport not created — port must be between 1 and 65535."

"Spacecraft ready. Identity and profile configured."

Controlled state vocabulary

One word per state, used everywhere — don't drift between synonyms. Readiness: Ready · Needs Work · Missing. Severity: Critical · Warning · Info · Nominal (CRIT/WARN/INFO/NOM). Quality: Good · Suspect · Bad. A thing that "failed" is "failed" in every view, never "Error" here and "Bad" there. The state words are part of the design system, like the colors that carry them.
