Layering

✓ The depth vocabulary (z-tiers, elevation, state films, highlights) is live in tokens.css; ◎ the visible elevation refactor (hover-as-film everywhere, blur reserve) is Phase 5.

Depth is not decoration — it is a model of attention and permission. Higher means “attend to me more”; modal means “you may not touch what is behind me.” The cue that makes it readable: light comes from above, so lifted things are lit on their top edge. Every depth trick exploits that.

Two systems — keep them separate

Elevation

How lifted something looks — a visual property. A small, behavior-named scale.

Stacking

Which element wins when two overlap — a structural property (z-order / DOM). A named tier scale.

They correlate but are not the same (a sticky header looks flat yet stacks high). The rule: never let them contradict — if A looks higher than B, A must also stack above B.

Cue stack, applied monotonically (more height → more cue): 1. surface tint (lighter = higher) — primary on dark. 2. a top-edge highlight (the lit edge) — the half Cadence is missing on surfaces, though it already exists on btn-primary. 3. backdrop-blur — floating & modal only. 4. occlusion — free. No drop-shadow: on near-black it barely reads.

Structural fix: three concepts are fused into one lightness ramp. Only ~4 rungs are elevation; input is a role (should reference a level) and hover is a state (a transient modifier). Splitting them is the same move as the token architecture.

Stacking — the ideal z-tier scale

600tooltip — always on top
500toast — transient info, above modals
400scrim + modal — dialog + its suppressing backdrop
300popover — dropdowns, menus (transient)
200chrome — persistent frame: sidebar, status bar
100sticky — pinned headers / toolbars
0content — normal flow

Values spaced 100 apart so you can insert without renumbering. Toast & tooltip sit above modal — transient info must stay visible over a dialog. The best implementation minimizes z-index entirely via portals (teleport overlays to the root; DOM order does the work); the named enum is the fallback for what can’t be portaled.
