Input

The one form field — <.input> from FormInputs. It owns the hud-label, the daisyUI control styling, and error display. Bind it with field={@form[:name]} inside <.form>; for standalone controls (filter boxes, phx-change selectors) pass name/value instead.

Usage

  • ✓ Use <.input> for every field — never hand-write a raw <input>, <select>, or <textarea>.
  • ✓ Bind with field={@form[:name]} in a form; errors render automatically once the field is touched.
  • ✓ For standalone controls (filters, phx-change selectors) pass name/value, and add compact to drop the wrapper margin.
  • ✗ Don't add a separate <label> — pass label and the component renders the hud-label for you.
  • ✗ Don't style error states by hand; the input-error border and text-error message come from the errors list.
