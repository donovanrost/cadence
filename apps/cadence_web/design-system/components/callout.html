Components

Callout

An inline contextual message that belongs where it appears — a failed import's reason, a warning about dropped selections, in-page guidance. Not a toast: transient action feedback goes through flash. role="alert" is built in. Status-tinted border and wash; text stays base-content for legibility.

Variants

:error
Import failed: unsupported schema version 3. Accepted: YAML (.yaml, .yml).
:warning
3 previously selected APIDs are not in this revision: 101, 104, 209.
:info
Decommutation follows the pinned profile. Changing the profile re-derives all packet claims.
:success
All 14 packets decommutated against Aurora Bus v3.

Usage

  • ✓ Use for in-page contextual state — validation failures next to their form, warnings scoped to a section, import failure reasons.
  • ✓ Pass id when tests or anchors need a hook; extra layout via class.
  • ✗ Never hand-write daisyUI alert alert-* — this component replaced every raw alert.
  • ✗ Not for transient action feedback ("Saved") — that's flash; and not for empty lists — that's <.empty_state>.
