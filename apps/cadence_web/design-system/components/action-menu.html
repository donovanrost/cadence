Action menu

The vertical-ellipsis menu for row and card secondary actions — <.action_menu id={"#{thing.id}-actions"}> with one <:action> slot per item (a <.link> or <button>). daisyUI dropdown styling driven by the DropdownMenu hook: a real button trigger with aria-expanded, arrow-key navigation, and Escape-to-close with focus return.

Keyboard & ARIA

ArrowDown (closed)Opens the menu and focuses the first item (click does the same). ArrowDown / ArrowUpMove focus through items, wrapping at both ends. Home / EndJump to first / last item. EscapeCloses and returns focus to the trigger. Tab · outside clickCloses without stealing focus back. rolesrole="menu" on the list, role="none" on each li; items are the links/buttons your slots render.

Usage

  • ✓ Use only when a row has real secondary actions beyond View — a View-only menu should be dropped (the Name-cell link already navigates).
  • ✓ Give every menu a unique id ("#{thing.id}-actions") — the hook and aria-controls depend on it.
  • ✓ Guard destructive items with data-confirm on a plain <button phx-click>.
  • ✗ Never put multiple action buttons directly in a table cell — fold them into one action menu.
  • ✗ Don't make rows navigate via phx-click or the menu — row navigation is the Name-cell link (text-primary hover:underline).
