Components

Empty state

The no-rows placeholder — <.empty_state title="No transports" />. A dashed panel with an optional icon (icon, base-content/30), a hud-label title (required), a description, and a primary create <.button> when action_label is set with action_navigate or action_patch. compact collapses everything to one muted line for inside a card or sub-panel.

Default — icon · title · description · action

No transports

Create a transport to describe an external capability for moving bytes.

Icon and description are optional; the action button renders only when action_label is set. Without icon the title sits flush at the top.

Compact — compact inside a card sub-panel

Pending invitations

No pending invitations.

compact renders only the title as text-sm text-base-content/60 — no border, icon, description, or action.

Usage

  • ✓ Use when a list has no rows — it replaces the list's <.card>/table entirely, not a row inside it.
  • ✓ Put the create action inside the empty state via action_label + action_navigate (or action_patch for modal flows).
  • ✓ Use compact for empty sub-sections within a card ("No runs yet.") where the full dashed panel would be too loud.
  • ✗ Don't hand-roll a "nothing here" div or drop a bare <.button> on a blank page — this component is the one empty pattern.
  • ✗ Don't stack extra buttons in it; one create action. Secondary paths belong on the page header or docs links.
