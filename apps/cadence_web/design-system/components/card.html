Card

Chrome is card bg-base-200 border-base-300. Two heading styles: an inline uppercase title, or a full-bleed heading bar with subtitle and actions. The cyan hud-corners brackets mark navigation and hero cards only — hover_glow applies them; corners opts a hero panel in. Status on a card is carried by the <.status_badge> inside it; there is no status border.

hover_glow — navigation card: corner brackets + cyan glow on hover

Usage

  • ✓ Chrome is card bg-base-200 border-base-300 — use <.card>, never raw class="card …".
  • ✓ Use hover_glow only on cards that are themselves navigation targets — it brings the hud-corners brackets with it. corners alone marks a non-navigating hero panel.
  • ✗ Don't put a status color on the card frame — the <.status_badge> inside owns status (the old accent attr double-encoded it and was retired).
  • ✗ Don't exceed 50 lines in a render function or 400 in a file — extract a private component first.
  • ✗ A one-off layout needing more than a couple class escapes may stay raw — leave a one-line comment saying why.
