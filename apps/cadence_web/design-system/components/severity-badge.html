Severity badge

Diagnostic counts — <.severity_badge severity={:critical} count={3} />. A status dot, an optional monospace count, and an abbreviated uppercase label (CRIT / WARN / INFO / NOM).

:critical3Crit :warning12Warn :infoInfo :nominalNom

Usage

  • ✓ Use for diagnostic counts / alarm severity — :critical / :warning / :info / :nominal.
  • ✓ Include count when showing how many (3 critical alarms); omit it for a bare state.
  • ✗ Don't use it for setup/readiness — that's <.status_badge>.
  • ✗ Don't animate the pill itself; pulse lives on status dots, used sparingly.
