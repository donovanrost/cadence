Components

Button

The canonical <.button>. Sharp, uppercase, tracked. Buttons never glow — primary carries a faint cyan rim instead. :sm is the default; :md is for form submits and page CTAs, :xs for inline table controls.

Variants

:primary
:secondary
:ghost
:danger

Variant names are the component's API; the emitted daisyUI classes differ — :danger renders btn-error btn-outline. Passing navigate / patch / href renders a <.link> styled as the same button ("New Transport" is a link, not a <button>). rest passes through: disabled, form, data-confirm.

Sizes

xs / sm / md

States

default
hover
focus
disabled
loading

Hover and focus are interaction states, shown here as static specimens. Loading is not a button variant — it's LiveView-driven via the phx-submit-loading / phx-click-loading classes (pair with phx-disable-with to swap the label). Disabled passes straight through to the underlying element.

Usage

  • ✓ Default to :sm. Reserve :md for form submits and page CTAs, :xs for inline table controls.
  • ✓ Use :danger (outline) for destructive actions — aborting a pass, deleting a record.
  • ✓ One primary action per view; demote the rest to :ghost or :secondary.
  • ✗ Never hand-write class="btn …" — always reach for <.button>.
  • ✗ Buttons never glow; glow is reserved for navigation and live / alert signals.
