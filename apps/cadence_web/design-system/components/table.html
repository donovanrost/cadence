Table

The canonical data table. Headers are hud-label; cells are monospace. Hovering a row reveals a cyan border-l-2 accent. Columns opt into align={:right} and mono; the Name cell is the row's link to its show page.

Usage

  • ✓ Row navigation is the Name-cell link (text-primary hover:underline) to the show page.
  • ✓ Right-align numeric columns (align={:right}); use mono for identifiers, versions, counts.
  • ✓ Sortable columns: per-col sort + table-level sort_by/sort_dir/on_sort — headers become buttons with aria-sort; round-trip the sort through the URL (see List controls).
  • ✓ Large collections: pass a LiveStream as rows — DOM ids derive automatically (override with row_id/body_id); an :empty slot renders the zero-row body.
  • ✓ Keep <.action_menu> only when a row has real secondary actions beyond View.
  • ✗ Never use whole-row phx-click, and never put multiple action buttons directly in a cell.
  • ✗ Tables needing checkboxes, expanders, or nesting stay hand-rolled — don't force them into <.table>.
