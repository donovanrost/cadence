Page header

The canonical page header: title block over the standard border-b border-primary/20 pb-4 rule, one per page. Navigation context goes above the title — a breadcrumbs trail (list of {label, path}, last item current) or a plain eyebrow label. Inline counts sit in :title_suffix; buttons and status pills in :actions.

Usage

  • ✓ One <.page_header> per page, at the top. Sections further down use <.section_header> (the in-card variant), never a second page header.
  • ✓ Pick one navigation context: breadcrumbs for hierarchy (Mission / Comms / Transports), eyebrow for a flat label — not both.
  • ✓ :title_suffix is for inline counts and IDs next to the title; subtitle is a sentence of description below it. They are not interchangeable.
  • ✓ Put page-level buttons and status pills in :actions — a <.button>, never raw class="btn …".
  • ✗ No back-links ("← Back to Comms") above the title — real pages use breadcrumbs; the last crumb is the current page and gets nil for its path.
  • ✗ Don't put text-base-content/NN next to hud-label — the label's own color wins the cascade and the utility is inert.
