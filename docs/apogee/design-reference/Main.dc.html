01 // Principles

Truth before calm

No data is a state. Stale is hatched and outranks nominal. Green is earned, never assumed.

Fleet first

Every view opens on the constellation and narrows to a plane, a group, a spacecraft.

The clock is king

UTC, MET and countdowns to AOS sit in the frame at all times. Time runs left to right.

Speak flight

AOS, LOS, uplink, GO / NO-GO. Operators already think in these words, so the UI uses them.

Shape carries meaning

State is coded by shape and color, so it reads in grayscale, at a glance, on a wall screen.

The console holds still

An ops screen you act from or watch live fits the viewport. Panes scroll, the page never does, and the commit action sits beside the state that justifies it. Reading views, setup and admin can scroll.

02 // State: shape plus color, never color alone

Critical#FF4D57

Diamond. Out of limits, a human acts now. Flashes once on arrival.

Caution#FFB020

Triangle. Trending to a limit, or a soft limit crossed.

Stale#A497FF

Hatched square. No fresh telemetry. Outranks nominal everywhere.

Nominal#2FD08A

Square. Fresh and in limits. Drawn dim in bulk so problems stand out.

Not set updashed

Dashed. App or source not installed. Offer to install, never imply clean.
