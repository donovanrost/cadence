Commanding · end to end

Sent is not done

Today commanding is one cramped page. Its first step is unclear, it caps targets at 25, and every target reads SCID —. In the new flow a command passes through seven stations, each with one owner and one clear exit. It turns green only when telemetry proves the spacecraft did what was asked.

BOARDS IN THIS ROW C-COMPOSE · C-APPROVE · C-UPLINK CONTINGENCY VARIANT · J3

The seven stations

01 · OPERATOR

Compose

Pick commands from the catalog and a target group. The arguments, ranges and units come from the database.

Exit: staged request
02 · CADENCE

Check

Identity, catalog version, argument ranges and constraints are checked per target, before anyone is asked.

Exit: all checks GO
03 · SECOND OPERATOR

Approve

Review exactly what will radiate and why. Approve, approve with exclusions, or send it back.

Exit: GO, signed
04 · CADENCE

Release

At each target's next AOS, at a time tag, or in waves with an automatic gate between them.

Exit: queued at station
05 · GROUND STATION

Radiate

Bytes leave the antenna inside a pass. You can abort any uplink until it starts.

Exit: radiated
06 · SPACECRAFT

Acknowledge

The spacecraft accepts the command and reports that it executed. No ACK schedules a retry at the next pass.

Exit: executed
07 · TELEMETRY

Verify

A verifier point reads the commanded value within its window. Only this turns the command green.

Exit: verified

R

Rules on every commanding screen

01
Identity on every lineName, SCID and profile on every target row, everywhere. A command screen never shows a dash where an identity belongs.
02
Target by query, not by cardProfile, plane, group or status, from 1 spacecraft up to the fleet. The query stays live until release.
03
The catalog writes the formTypes, ranges, units and enums come from the XTCE database. A value out of range can't be staged.
04
Show what will radiateThe approver sees the encoded packet, not a summary of it.
05
Two people for anything hazardousYou can't approve your own request. Hazardous commands also need the flight director.
06
Fleet changes go in wavesA canary wave first. Each later wave waits on a gate that the verifiers decide.
