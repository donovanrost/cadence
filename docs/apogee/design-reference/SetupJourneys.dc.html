Setup · the ground segment behind the console

Configure the fleet, not each spacecraft

Setup is used by mission engineers and admins, weekly or monthly, not every shift. It lives behind an OPS / SETUP switch in the top bar, so it never crowds the console. The jobs are rarer but riskier, so every change is staged, diffed and applied as a revision.
