## Overall
The second wave holds the language. Takeovers (U19) are consistent across Compose, K1 and the wizard;
the honest-unavailable pattern is everywhere it should be (profile routing/overrides, Contact
planning, Contacts D1, K1 not set up, service identities). **Mobile J6 is the standout**: the paged
alarm view matches Mobile.md almost exactly (alarm panel, sparkline, 48px Acknowledge / Hand off,
escalation callout, honest timing, the "desktop only" caption). The Changes checks + holds gate works
as designed. The main gaps are identity (raw ids where names belong) and a few raw keys in copy.
