The console reads as one instrument. The shell, panels, status grammar, type roles and time formats
are consistent across all 15 screens. Nothing scrolls horizontally at 390. **The not-available
states read as deliberate, not broken**: every one uses the same pattern (off mark + label headline
+ one sentence of cause + an action where one exists), stays inside its panel, and never leaves a
blank or a stuck spinner (Now A4, Investigate B2, Catalog, Readiness, Telemetry plot, Alarms with
ground limits off). The one exception is copy that passes a raw server error through (item 10).
