## [0.1.0] - 2026-08-21

### Added

- Bounded parsing for XTCE 1.3 XML documents.
- A source-oriented document and element tree with traversal helpers.
- Pinned offline validation against the normative XTCE 1.3 schema.
- Binary and filesystem APIs with explicit validation and resource-limit
  errors.
