# @cadence/apogee-ui

The Apogee design language (docs/apogee/ux/design-language.md) for the Cadence console SPA
(`apps/console`): Tailwind v4 tokens (`apogee.css`), the `Ap*` Vue components, and the one
time/number formatting module. Owner: lead (values of tokens: ux).

This is a deliberate second design system for the Apogee console, separate from `@cadence/ui`
(the production design system for the federated host). Do not import one into the other.
